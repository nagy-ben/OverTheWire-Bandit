## Goal:
The password for the next level is stored in a file called - located in the home directory
## Solution:
I logged into the bandit1 account using the same ssh location and the password from level0. There was a file called "-" in the directory. Could'nt open with the simple 'cat -' command. The was a link on the tasks page that when the file name is a special character: "So if you want to open this type of file you have to specify the full location of the file such as ./- .For eg. , if you want to see what is in that file use cat ./-"
So i used 'cat ./-' and the password was: PK8fYLZg2hnHSz83plBL1iEPKdD3QToB
